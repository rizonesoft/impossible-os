## TODO-02 — Environment Variables & Process ABI 🔄 MIGRATE

**Source file to migrate from (then delete):**
- `todo-old/010-Kernel-Foundations/TODO-025-Environment-Variables.md` — all sections

Create `todo/11-user-platform-sdk/TODO-02-env-vars-process-abi.md`. The scheduler, exec, and PEB/TEB structures are done (→ XREF `02-kernel-core`); this TODO wires the per-process environment, `%VAR%` expansion, and the correct argument-passing ABI that every user-mode program depends on. Sections: (1) per-process environment storage — `struct task` gets `char **environ` array (NULL-terminated, same as POSIX `environ[]`); each entry is a `"KEY=VALUE"` string; `env_get(task, name)` linear scan for `"NAME="` prefix; `env_set(task, name, value)` — allocate new `"NAME=VALUE"` string, replace existing or append; `env_unset(task, name)` — remove and compact array; `env_list(task, buf, max)` dumps all vars; store in user-mode accessible region of PEB (`PEB.ProcessParameters.Environment` flat block); (2) system default variables — populate at process creation from Registry: `PATH` = `HKLM\SYSTEM\Environment\Path` (default `C:\Impossible\Bin;C:\Programs\`); `SYSTEMROOT` = `C:\Impossible\`; `TEMP` = `C:\Temp\`; `HOME` = `C:\Users\{username}\` (from current user); `USERNAME` = current user name; `COMPUTERNAME` = `HKLM\SYSTEM\Network\Hostname`; `OS` = `"Impossible OS"`; per-user overrides from `HKCU\Environment`; (3) `%VAR%` expansion — `env_expand(input, output, max)`: state machine walks input, on `%` starts collecting name until next `%`, calls `env_get()` and substitutes; if name not found, leave `%NAME%` literal; depth limit 4 (detect cycles); `env_expand_path(template, argv0, output)` for file association command templates (e.g., `"notepad.exe %1"` → substitute `%1` with file path); used by: shell command parsing, `CreateProcess` command-line expansion, file associations; (4) `SYS_GETENV` / `SYS_SETENV` syscalls — `SYS_GETENV(name, buf, max)` → reads from current task environ; `SYS_SETENV(name, value)` → calls `env_set` on current task; `SYS_UNSETENV(name)` → `env_unset`; user-mode `GetEnvironmentVariableA/W` and `SetEnvironmentVariableA/W` wrap these; (5) PATH-based command lookup — `shell_resolve_command(name, full_path)`: if name contains `\` or `.exe`, try directly; else iterate PATH directories split by `;`; for each dir, try `dir\name` and `dir\name.exe`; return first existing executable; cache in shell session (last 8 lookups) for speed; (6) argv/argc process ABI — `exec_build_stack(argv[], envp[], stack_top)`: lay out user-mode stack per System V AMD64 ABI: `[RSP]` = argc (uint64), `[RSP+8..RSP+8*(N+1)]` = argv[] pointers, `[RSP+8*(N+1)]` = NULL, `[RSP+8*(N+2)..]` = envp[] pointers, NULL; each string is copied to the page below stack; shell: parse command line → `argv[]` (handle quoted args with `"..."`, escaped chars `\"` and `\\`, `%VAR%` expansion); child `main(int argc, char *argv[])` receives correct values; Win32 `GetCommandLineA()` returns flat string from `PEB.ProcessParameters.CommandLine`; (7) shell `.profile` — on shell startup: check `C:\Users\{name}\.profile` via VFS; read line-by-line; execute each as a shell command (`SET VAR=VALUE` → `env_set`; `#` → skip; other commands run normally); ship default `.profile` in ISO with `PATH` and `TEMP` set; `HKCU\Software\Impossible\Shell\SkipProfile` (1 = bypass); (8) `set` / `echo` shell commands — `set` (no args) → print all env vars; `set NAME=VALUE` → call env_set; `set NAME=` → env_unset; `echo %VAR%` → expand + print; `where <command>` → PATH lookup + print full path; `env` command → same as `set` no-args.

## TODO-03 — ELF Relocations & Kernel Module System 🔄 MIGRATE

**Source file to migrate from (then delete):**
- `todo-old/010-Kernel-Foundations/TODO-026-ELF-Shared-Libraries.md` — all sections

Create `todo/11-user-platform-sdk/TODO-03-elf-reloc-kernel-modules.md`. The kernel is loaded as ELF by the UEFI bootloader; this TODO implements the ELF relocation engine needed for two subsystems: kernel modules (loadable drivers) and Linux ELF compat (→ XREF `09-services-security/TODO-10`). PE/Win32 DLL loading is the native path (→ XREF `09-services-security/TODO-07`). Sections: (1) ELF relocation engine — `src/kernel/elf_reloc.c`; parse section headers (SHT_SYMTAB, SHT_RELA, SHT_REL); build kernel symbol table from exported symbols (`.kmod` entry point + all `EXPORT_SYMBOL`-marked functions); apply relocations: `R_X86_64_64` (absolute 64-bit), `R_X86_64_PC32` (PC-relative 32-bit), `R_X86_64_PLT32` (PLT call), `R_X86_64_GLOB_DAT` (GOT entry), `R_X86_64_JUMP_SLOT` (PLT slot, lazy binding); `elf_resolve_symbol(name)` searches kernel symbol table + already-loaded modules; (2) kernel module format `.kmod` — ELF relocatable object (`ET_REL`) with `.kmod_init` and `.kmod_exit` sections; `struct kmod_info` at start of `.kmod_info` section: name[32], version[16], init_fn ptr, exit_fn ptr, dependencies[8]; compile drivers as `.kmod` with `clang-19 --target=x86_64-elf -r` (relocatable); `kmod_load(path)` loads from VFS, resolves relocations, calls `init_fn`; `kmod_unload(name)` calls `exit_fn`, frees memory; (3) kernel module loader — `kmod_load(path)`: read ELF via VFS; validate `EI_CLASS=64-bit`, `ET_REL`, `EM_X86_64`; allocate memory (exec+rw) with `pmm_alloc_contiguous`; copy section data; apply all RELA relocations; call `.kmod_init`; add to loaded modules list; `kmod_list()` returns names of loaded modules; auto-load: scan `C:\Impossible\System\Drivers\*.kmod` at boot; kernel cmdline `nokmod=<name>` to skip specific modules; (4) kernel symbol export — `EXPORT_SYMBOL(fn)` macro emits a `struct kmod_export { const char *name; void *addr; }` entry in `__ksymtab` section; build-time linker script collects all entries into a flat array; `ksym_lookup(name)` binary search (sorted at link time); allows modules to call any exported kernel function by name; (5) dlopen/dlsym for Linux compat — `dlopen(path, flags)` used by Linux ELF compat layer (→ XREF `09-services-security/TODO-10`): if path is a `.so`, try to load as ELF shared object (`ET_DYN`); apply PIC relocations, build GOT/PLT; `dlsym(handle, name)` searches the module's `.dynsym`; `dlclose(handle)` decrements ref count; `RTLD_DEFAULT` searches all loaded ELF modules; PE DLL equivalent is `LoadLibrary`/`GetProcAddress` (→ XREF `09-services-security/TODO-08`); (6) GOT/PLT lazy binding — for ELF `ET_DYN` modules: PLT stubs initially call `elf_plt_resolve(module, slot_idx)`; on first call, `elf_plt_resolve` looks up symbol, patches GOT entry with real address, returns; subsequent calls go direct via GOT; supports RTLD_LAZY (default) and RTLD_NOW (resolve all at load time); (7) module hot-swap (stretch) — `kmod_reload(name)` = `kmod_unload` + `kmod_load`; used by developers iterating on driver code without rebooting; requires drivers to support clean `exit_fn` (release all IRQs, free DMA buffers, deregister device); `kmod reload <name>` shell command; (8) `lsmod` / `insmod` / `rmmod` shell commands — `lsmod`: print loaded modules (name, size, init_addr, dependencies); `insmod <path.kmod>`: load module from path; `rmmod <name>`: unload module; `modprobe <name>`: search `C:\Impossible\System\Drivers\` + auto-resolve dependencies.

## TODO-04 — NTDLL & User-Mode Runtime 🆕 NEW

Create `todo/11-user-platform-sdk/TODO-04-ntdll-user-runtime.md`. PE loader, syscall interface, and Win32 API stubs are done (→ XREF `09-services-security/TODO-07`/`08`); this TODO builds `ntdll.dll` — the user-mode runtime that sits between every Win32 program and the kernel, providing the heap, loader, TLS, and vectored exception handling that all user-mode code depends on. Sections: (1) ntdll.dll structure — `src/user/ntdll/ntdll.c` compiled as PE DLL; export table contains all Nt*/Rtl*/Ldr* functions; statically linked into every process at load time by PE loader (always mapped at `0x7FF00000000`); no import dependencies (it is the lowest user-mode layer); split into: `ntdll_syscalls.asm` (thin syscall wrappers), `ntdll_heap.c` (RtlHeap), `ntdll_loader.c` (LdrLoadDll), `ntdll_tls.c` (TLS), `ntdll_except.c` (VEH), `ntdll_sync.c` (critical sections); (2) RtlHeap — process heap implementation; `RtlCreateHeap(flags, base, reserve, commit, lock, params)` initializes a heap from a VirtualAlloc'd region; free-list + best-fit allocator with 8-byte alignment; `RtlAllocateHeap(heap, flags, size)` → find free block or expand heap; `RtlFreeHeap(heap, flags, ptr)` → coalesce neighbors; `RtlSizeHeap(heap, flags, ptr)` → returns block size; `HEAP_ZERO_MEMORY` flag: zero-fill on alloc; `GetProcessHeap()` returns default process heap (created at process init); `HeapAlloc`/`HeapFree`/`HeapCreate`/`HeapDestroy` in `kernel32.dll` call through to Rtl equivalents; (3) LdrLoadDll (PE DLL loader) — `LdrLoadDll(path, flags, basename, hmod_out)`: search DLL in: process directory, `C:\Impossible\System32\`, `C:\Impossible\Bin\`, `PATH`; if already loaded (check by base name in LDR module list), return existing handle; else PE-load (map sections, relocate, import-resolve recursively); add to `PEB.Ldr` doubly-linked list (`LDR_DATA_TABLE_ENTRY`); call DllMain with `DLL_PROCESS_ATTACH`; `LdrGetProcedureAddress(hmod, name, ordinal, addr_out)` walks export directory by name hash or ordinal; `LdrUnloadDll(hmod)` calls `DLL_PROCESS_DETACH`, removes from list, frees memory; `LoadLibraryA/W` → `LdrLoadDll`; `GetProcAddress` → `LdrGetProcedureAddress`; (4) thread-local storage (TLS) — `TlsAlloc()` returns a TLS index (0–63); per-thread TLS array in TEB at `TEB.TlsSlots[64]`; `TlsSetValue(index, value)` writes to `TEB.TlsSlots[index]`; `TlsGetValue(index)` reads; `TlsFree(index)` releases slot; PE TLS callbacks: scan PE `DataDirectory[9]` (IMAGE_TLS_DIRECTORY), call each `TlsCallback` on thread create/destroy; `FlsAlloc`/`FlsSetValue`/`FlsGetValue`/`FlsFree` (fiber-local storage, same mechanism); GS register points to TEB on x64; (5) vectored exception handling (VEH) — `AddVectoredExceptionHandler(first, handler)` adds to VEH list; on exception (kernel delivers via `NtRaiseException`): walk VEH list calling each handler; handler returns `EXCEPTION_CONTINUE_EXECUTION` or `EXCEPTION_CONTINUE_SEARCH`; if none handle: walk SEH frames from TEB.ExceptionList (→ XREF `02-kernel-core/TODO-10`); if still unhandled: call `UnhandledExceptionFilter` → show crash dialog with exception code + stack trace; `RemoveVectoredExceptionHandler(handle)`; `RaiseException(code, flags, nargs, args)` → `NtRaiseException`; (6) process startup (CRT0) — `user/crt0.asm`: PE entry `_DllMainCRTStartup` (for DLLs) and `_mainCRTStartup` (for EXEs); EXE startup: call `RtlHeap` init, TLS init, call all static initializers (`.ctors` section), call `WinMain(hInstance, NULL, cmdline, SW_SHOW)` or `main(argc, argv)`, call `ExitProcess(return_val)`; DLL startup: call `DllMain(hmod, reason, reserved)`; static C++ constructors: collect function pointers from `.ctors` section (LLVM emits them), call in order; (7) user-mode libc shims — thin C library for user-mode programs: `printf` → `WriteConsoleA`; `malloc`/`free` → `HeapAlloc`/`HeapFree(GetProcessHeap())`; `fopen`/`fread`/`fwrite`/`fclose` → `CreateFile`/`ReadFile`/`WriteFile`/`CloseHandle`; `exit(n)` → `ExitProcess(n)`; `abort()` → `RaiseException(STATUS_FAIL_FAST_EXCEPTION,...)`; placed in `user/lib/libc.lib` (linked by default); allows programs written with standard C idioms to compile without modification; (8) fiber API — `CreateFiber(stack_size, fn, param)` allocates fiber stack + context; `SwitchToFiber(fiber)` saves current context, restores target; `ConvertThreadToFiber(param)` converts calling thread; `DeleteFiber(fiber)`; stored as `FIBER` struct with stack pointer + register save area; basis for coroutine-style async I/O in future.

## TODO-05 — Win32 Subsystem Server (CSRSS) 🆕 NEW

Create `todo/11-user-platform-sdk/TODO-05-win32-subsystem.md`. NTDLL, PE loader, and the Win32 API stubs are done; the Win32 subsystem server bridges user-mode processes and the kernel desktop/WM, managing per-thread message queues, window class registration, and the message loop that every GUI app depends on. `UnregisterClass(name, hInstance)`; `GetClassInfo(hInstance, name, wndclass_out)`; built-in system classes: "BUTTON", "EDIT", "STATIC", "LISTBOX", "COMBOBOX", "SCROLLBAR" — map to `CTRL_*` widget implementations from `07-graphics-ui/TODO-04`; `WM_CLOSE` → `DestroyWindow`; `WM_DESTROY` → `PostQuitMessage(0)`; `WM_SIZE` → update window rect; `WM_MOVE` → update position; `WM_KEYDOWN`/`WM_KEYUP` → `TranslateMessage` generates `WM_CHAR`; `WM_LBUTTONDOWN`/`WM_MOUSEMOVE` → hittest + dispatch to child; (4) Win32 painting model — `BeginPaint(hwnd, ps_out)` fills `PAINTSTRUCT` (hdc, fErase, rcPaint); returns HDC mapped to window's compositor surface; `EndPaint(hwnd, ps)` flushes dirty region to compositor; `InvalidateRect(hwnd, rect, erase)` marks region dirty + queues `WM_PAINT`; `ValidateRect(hwnd, rect)` clears dirty; `UpdateWindow(hwnd)` forces immediate `WM_PAINT` dispatch; HDC model: map Win32 HDC to `gfx_surface_t*`; GDI calls on HDC translate to `gfx_*()` primitives; `CreateCompatibleDC` / `SelectObject` / `DeleteDC` (→ XREF `07-graphics-ui/TODO-11 §2`); (5) message filters & accelerators — `TranslateMessage(msg)`: converts `WM_KEYDOWN` with character key + modifier state → `WM_CHAR`/`WM_SYSCHAR`; `WM_SYSKEYDOWN` (Alt+key) → `WM_SYSCOMMAND` (SC_CLOSE for Alt+F4, SC_MINIMIZE for Alt+Space→n); accelerator tables: `LoadAccelerators`, `TranslateAccelerator` → match MSG against table, post `WM_COMMAND(id)`; `PostQuitMessage(exit_code)` posts `WM_QUIT` to thread queue; `GetMessage` returns 0 on `WM_QUIT` → app exits message loop; (6) window subclassing — `SetWindowLongPtrA(hwnd, GWLP_WNDPROC, new_proc)` replaces WndProc, returns old; `CallWindowProc(old_proc, hwnd, msg, w, l)` chains to previous WndProc; property store: `SetProp`/`GetProp`/`RemoveProp` — per-window hash map of name→HANDLE pairs; `GWLP_USERDATA` for arbitrary user pointer; (7) inter-process window messaging — `FindWindow(class, title)` scans all windows; `SendMessageA/W` crosses process boundary via kernel IPC pipe; `PostMessageA/W` enqueues cross-process; `WM_COPYDATA` (COPYDATASTRUCT): serialize data into kernel-allocated shared buffer, send to target; `BroadcastSystemMessage(flags, recipients, msg, w, l)` → all top-level windows; (8) common dialog boxes — `MessageBoxA/W` (→ already implemented); `ChooseColor(CHOOSECOLOR*)` → color picker dialog; `ChooseFont(CHOOSEFONT*)` → font picker; `CommDlgExtendedError()` → last dialog error; these call into the Dialog System from `07-graphics-ui/TODO-05`.
