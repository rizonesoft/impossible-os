**Source file to migrate from (then delete):**

Create `todo/07-graphics-ui/TODO-02-animation-engine.md`. The theme system is done; animations are the next prerequisite because window open/close, Start Menu slide, notification slide-in, and context menu pop all depend on the animation tick running inside the compositor loop. Sections: (1) core tween engine — `gfx_tween_t` struct (from_val, to_val, current, duration_ms, elapsed_ms, easing_fn, on_complete callback, active flag) in `include/kernel/gfx/gfx_animate.h`; `gfx_tween_start(tw, from, to, duration_ms, easing)`, `gfx_tween_update(tw, delta_ms)` advances elapsed and writes interpolated value to `current`, `gfx_tween_value(tw)` getter; all arithmetic in 16.16 fixed-point (shift by 16); (2) easing functions — `GFX_EASE_LINEAR`, `GFX_EASE_IN_QUAD`/`OUT_QUAD`/`IN_OUT_QUAD`, `GFX_EASE_IN_CUBIC`/`OUT_CUBIC`/`IN_OUT_CUBIC`, `GFX_EASE_BOUNCE` (elastic bounce at end), `GFX_EASE_BACK` (slight overshoot then settle); all take 16.16 `t` (0→1<<16), return shaped 16.16 value; (3) global animation manager — `anim_mgr.c`: fixed table of 64 `gfx_tween_t*` pointers, `anim_mgr_add(tw)` registers (returns -1 if full), `anim_mgr_cancel(tw)` removes, `anim_mgr_tick(delta_ms)` advances all active tweens and auto-removes completed; wired into compositor main loop before compositing; delta_ms from `(current_pit_ticks - last_ticks) * 1000 / PIT_HZ`, capped at 33 ms to prevent animation jumps; (4) window transition animations — per-window `wm_anim_state_t` (tweens for x, y, w, h, opacity, scale): window open: scale 90→100% + opacity 0→255 (200 ms ease-out-cubic); window close: scale 100→90% + opacity 255→0 (150 ms ease-in-quad); minimize: slide position toward taskbar button rect (250 ms ease-in-quad); restore: expand from taskbar button rect (250 ms ease-out-cubic); maximize: expand to fill screen (200 ms ease-out-cubic); snap left/right: slide+resize to half (200 ms); menu popup: scale-Y 0→100% from top (150 ms ease-out-quad); (5) Registry controls — `HKCU\Software\Impossible\Theme\EnableAnimations` DWORD (default 1): when 0, all `anim_mgr_add()` calls immediately snap to final value; `AnimationSpeed` DWORD (default 100 = 1×, range 50–200): scales all durations; (6) spring physics (stretch) — `spring_t` (position, velocity, target, stiffness, damping); `spring_update(sp, delta_ms)` Hooke's law integer step: `force = -k*(pos-target) - d*velocity`; `spring_settled(sp)` when `|velocity| < threshold`; apply to: window restore bounce, elastic scroll overshoot, drag-release snap-back; (7) compositor integration checklist — non-animating frames: skip compositor redraw if no dirty rects (existing dirty rect system); animating windows: force redraw each frame; VSync-aware delta capping; `EnableAnimations=0` reduces-motion path.
