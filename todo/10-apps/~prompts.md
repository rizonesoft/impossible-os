Sections: (1) SSH2 transport — `src/apps/ssh/ssh.c`; TCP connect to server port 22; version exchange: send `SSH-2.0-ImpossibleOS_1.0\r\n`, read server banner; key exchange: `SSH_MSG_KEXINIT` with `curve25519-sha256` preferred, receive server's KEXINIT; `SSH_MSG_KEX_ECDH_INIT` with ephemeral Curve25519 pubkey (via `monocypher crypto_x25519_public_key`); receive `SSH_MSG_KEX_ECDH_REPLY` (server host key + server ephemeral pubkey + signature); compute shared secret via `crypto_x25519`; derive session keys using HKDF-SHA256 (server host key fingerprint for TOFU verification); `SSH_MSG_NEWKEYS` — begin using ChaCha20-Poly1305 (or AES-128-CTR + HMAC-SHA256) for all subsequent traffic; sequence number counter on each side; (2) authentication — `SSH_MSG_SERVICE_REQUEST "ssh-userauth"`; password auth: `SSH_MSG_USERAUTH_REQUEST` with method `"password"`, username, password (sent encrypted); on failure: retry up to 3 times; `SSH_MSG_USERAUTH_SUCCESS`; stretch: public key auth with Ed25519 keypair from user's `C:\Users\{name}\AppData\ssh\id_ed25519` (auto-generate on first use, store pubkey for `~/.ssh/authorized_keys` copy); (3) interactive channel — `SSH_MSG_CHANNEL_OPEN "session"`; `SSH_MSG_CHANNEL_REQUEST "pty-req"` with `TERM=xterm-256color`, cols/rows from terminal size; `SSH_MSG_CHANNEL_REQUEST "shell"`; bidirectional data: WM keyboard events → `SSH_MSG_CHANNEL_DATA` → network; network receive → `SSH_MSG_CHANNEL_DATA` → `terminal_put_chars()` (renders ANSI in terminal emulator from `08-desktop-shell/TODO-08`); window resize → `SSH_MSG_CHANNEL_REQUEST "window-change"` with new cols/rows; (4) shell integration — `ssh user@host` opens new terminal window (or tab if terminal already open) running SSH session; `ssh user@host -p 2222` custom port; `ssh -i C:\path\to\key user@host` explicit identity file; host fingerprint TOFU: on first connect store fingerprint in `HKCU\Software\Impossible\SSH\KnownHosts\{host}`; warn on mismatch ("WARNING: Remote host identification changed!"); (5) SCP file transfer — `scp user@host:/remote/path C:\local\path` download; `scp C:\local\file user@host:/remote/path` upload; uses `SSH_MSG_CHANNEL_REQUEST "exec" "scp -f /path"` SCP subsystem; progress bar (bytes/total/KB/s); (6) SSH config — `C:\Users\{name}\AppData\ssh\config` INI format: `Host alias` stanzas with `HostName`, `User`, `Port`, `IdentityFile`; `ssh alias` resolves from config; `HKCU\Software\Impossible\SSH\DefaultUser` fallback username; (7) `sftp` command (stretch) — `sftp user@host` interactive file transfer using SSH subsystem `sftp`; subcommands: `ls`, `cd`, `get`, `put`, `rm`, `mkdir`, `bye`; more reliable than FTP (encrypted, single connection).
