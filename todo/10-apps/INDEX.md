# 10 Apps

This domain covers end-user applications and utilities shipped with the OS, whether graphical or command-line.

## Belongs Here

- Terminal, shell, file manager, settings, task manager, browser, email, and similar apps.
- Built-in CLI tools such as disk utilities or other user-facing command programs.
- App-specific UX, workflows, and feature backlog that does not define a shared platform service.

## Does Not Belong Here

- Reusable system services or shared policy engines. Put that in [09 Services Security](../09-services-security/INDEX.md).
- Platform ABI, SDK, and compatibility contract work. Put that in [11 User Platform SDK](../11-user-platform-sdk/INDEX.md).
