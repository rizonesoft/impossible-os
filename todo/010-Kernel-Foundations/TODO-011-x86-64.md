# 011-x86-64 — x86-64 Architecture Enhancements (Intel & AMD)

> **Goal:** Leverage modern x86-64 architectural features from both Intel and AMD
> to improve kernel performance, security, and capability. The current kernel
> operates in basic Long Mode with a flat GDT, legacy IDT, SSE2 SIMD, and
> `SYSCALL`/`SYSRET`. This TODO covers CPUID-based feature detection, EFER
> hardening, XSAVE state management, AVX/AVX-512/AVX10 vector extensions,
> APX (32 GPRs), FRED (replace IDT), LKGS, UINTR, MSR management, Zen chiplet
> topology & NUMA, AMD IBS profiling, Write-Combining optimization, OSVW
> errata workarounds, and virtualization detection — per the Intel SDM v090,
> AMD64 APM Volumes 1–5, PPR, and Software Optimization Guides.

> [!CAUTION]
> **Memory Rule:** Use `pmm_alloc_contiguous()` for ALL buffers > 4 KB. `kmalloc` is ONLY for small kernel structs (≤ 4 KB). See `rules.md` Known Gotchas.

## 5. Intel APX (Advanced Performance Extensions) *(Future)*

## 6. FRED (Flexible Return and Event Delivery)

### 6.1 Replace IDT with FRED

**Prompt:** FRED replaces the legacy IDT mechanism for interrupt/exception delivery. Instead of vector-based dispatch through a memory table, FRED delivers all events to a single kernel entry point with the event type and vector in registers. Benefits: atomic full-context establishment, native NMI nesting protection, CR2 preserved on stack (no transient loss), no SWAPGS needed (uses LKGS), and native CET shadow stack protection. The legacy IDT has severe edge cases with nested NMIs, stack corruption, and speculative execution side-channels. FRED eliminates all of them. Enable via `CR4.FRED` (bit 32) and configure `IA32_FRED_CONFIG` MSR. After completing all items, mark every item as `[x]`, update this prompt to a verification prompt, run `bash scripts/build.sh clean`, and commit as `"kernel: FRED event delivery"`. - [ ] Enable FRED: set `CR4.FRED` (bit 32)
- [ ] Configure `IA32_FRED_CONFIG` MSR:
  - [ ] Set kernel entry point address (single unified handler)
  - [ ] Set kernel stack pointer for each event level
- [ ] Implement unified FRED entry handler:
  - [ ] Read event type from register (interrupt, trap, fault, NMI, syscall)
